Q.2 Short Question (Marks: 2) Board Marking Scheme

Q: Define Virtual Functions with respect to Run-time Polymorphism.

Model Answer for Full Marks:

A virtual function is a member function declared within a base class and overridden by a derived class. It instructs the compiler to perform dynamic binding (run-time polymorphism) using a base class pointer.

Q.3 Detailed Question (Marks: 8) Complete Solution

Q: Write a complete C++ program demonstrating Method Overriding and Virtual Functions.

#include <iostream>
using namespace std;

class Animal {
  public:
    virtual void sound() { cout << "Default Animal Sound"; }
};

class Dog : public Animal {
  public:
    void sound() override { cout << "Bark: Bow Wow"; }
};
