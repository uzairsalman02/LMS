# Performance

Targets:
- fast navigation
- minimal loading on tab changes
- good experience on ordinary Pakistani mobile connections
- no unnecessary full-page reloads

Practices:
- server rendering where useful
- paginate large datasets
- lazy-load heavy interactives
- optimize images/PDF delivery
- avoid unnecessary dependencies
- use skeletons only where useful
- cache safe read-heavy data
- monitor client console and runtime errors
- test mobile widths and low-bandwidth behavior
