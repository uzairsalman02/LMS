# Question System

Supported types:
MCQ, short, long, numerical and programming where syllabus requires.

Metadata:
board, class, subject, chapter, topic, year, session/paper, marks,
difficulty, type, source, answer, explanation, published state.

Question workflow:
Create/import → classify → map to topic → answer/solution → quality review → publish.

Repeated questions:
1. normalize text
2. exact matching
3. near/concept similarity
4. confidence score
5. admin verification
6. publish repeat history

Never claim a question is repeated solely because an AI model guessed it.
