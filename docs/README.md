# CS Companion — Project Documentation

## Purpose
A web-first Computer Science learning platform for Pakistan's Class 11 and 12 students, initially Punjab Board. The product combines structured learning, interactive examples, practice, past papers, progress, revision and an AI tutor.

## Core learning loop
Learn → Understand → Interact → Practice → Test → Analyze → Revise

## Target
- Class 11 Computer Science
- Class 12 Computer Science
- Initial board: Punjab Board
- Web-first, responsive/mobile-first
- Android later through Capacitor
- Content must be source-aware and admin-reviewed

## Working model
ChatGPT: architecture, research, content strategy, prompts, review and troubleshooting.
Antigravity: implementation, automation, research assistance, extraction and testing.
Admin/product owner: final approval before educational content is published.

## Frozen rule
Do not expand the MVP to other subjects/boards until the Punjab Board Computer Science product is stable.
