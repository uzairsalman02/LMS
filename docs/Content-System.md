# Content Research & Acquisition System

This is a core project subsystem.

## Content ownership
The user should not have to manually type the entire textbook, syllabus or past-paper library.

## Research priority
1. Official Punjab/PCTB/BISE sources
2. Other reputable educational sources when necessary
3. AI-generated explanations only as original teaching material, never as the authority for official syllabus facts

## Pipeline
Official sources
→ source registry
→ book/syllabus extraction
→ chapter detection
→ topic mapping
→ question extraction
→ question classification
→ duplicate/repeat detection
→ AI-assisted explanation generation
→ admin review
→ publish

## Content types
- syllabus
- chapters/topics
- original explanations
- worked examples
- interactive examples
- MCQs
- short/long questions
- programming/numerical questions where applicable
- past papers
- answers/solutions
- revision notes
- flashcards

## Copyright rule
Do not simply republish copyrighted textbooks as a substitute for the book. Use lawful/publicly available sources and create original explanations and learning material. Preserve source attribution/metadata where appropriate.

## Verification
AI may suggest classifications, answers or repeats. Official/source verification and admin approval are required before high-stakes educational content is published.
